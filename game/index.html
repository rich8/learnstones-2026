3. Using relative directions

Pygame Code (click here) 
  x,y = 0
  dx,dy = 0
  while 1==1:       # game loop
    dx = cos(heading)
    dy = sin(heading)
    x = x + dx
    y = y + dy
    checkevents()   # call the event handler
  
  def checkevents()
    global heading
    for event in pygame.event.get():
      if event.type == pygame.keyDOWN:
        if event.key == pygame.k_RIGHT:
          heading = heading + 2
